DESIGN STYLE The website should communicate: Intelligence + AI + Technology + Innovation + Future Make it look: Futuristic Premium Clean Intelligent Modern Professional Easy to navigate Avoid a generic template or excessive visual effects.

COLOUR PALETTE Use ONLY this primary colour system: Deep Blue: #0B1F3A — main background White: #FFFFFF — text and clean surfaces Silver Ash: #B8BEC7 — borders, secondary text and metallic details Cobalt Blue: #0047AB — buttons, highlights, interactive elements and glow Keep Deep Blue dominant, with Cobalt Blue used as the main accent.

3D + MOTION Add tasteful, high-quality 3D and motion design. Use where appropriate: Interactive 3D brain/neural network Floating futuristic objects Particles Neural connections Depth and lighting Parallax Scroll animations Smooth page transitions Hover effects 3D card interactions Animated statistics The main 3D visual should represent intelligence, AI, neural networks, or digital knowledge. Make 3D elements subtly respond to mouse movement and scrolling. Do not overuse animations. They should enhance the UX, not distract users.

NAVIGATION & UX Make navigation extremely simple and intuitive. Include: Clean sticky/floating navbar Clear navigation labels Obvious CTAs Active navigation states Responsive mobile menu Smooth scrolling Users should always understand: Where they are → Where they can go → What they should do next.

RESPONSIVE DESIGN Make the entire website excellent on: Desktop Laptop Tablet Mobile Optimize or reduce heavy 3D effects on mobile and low-powered devices. Prevent horizontal scrolling and maintain excellent readability.

ACCESSIBILITY & PERFORMANCE Ensure: Good colour contrast Keyboard navigation Visible focus states Semantic HTML Accessible buttons/forms Fast loading Optimized images and 3D Smooth performance Respect prefers-reduced-motion.

FINAL RESULT The final website should feel like a next-generation intelligence/technology platform. Think: Deep Blue + White + Silver Ash + Cobalt Blue + 3D Intelligence + Smooth Motion + Simple UX.
